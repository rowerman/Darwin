# CIS Benchmark: 5.1.4 Minimize access to create pods

**编号**: 5.1.4
**级别**: Level 1
**描述**: 在某个命名空间内创建 Pod 的权限，可能会为权限提升行为提供多种可乘之机，例如为这些 Pod 分配特权服务账户，或是挂载可访问敏感数据的 hostPath 路径（除非已部署 Pod 安全策略来限制此类访问）。
因此，应将创建新 Pod 的权限限制在尽可能小的用户群体范围内。在集群中创建 Pod 的权限会增加权限提升的风险，因此在可行的情况下，应对其加以限制。

**影响**: 需要注意的是，不要移除系统组件对 Pod 的访问权限 —— 这些组件的运行依赖该权限。

**审计方法**: 检查那些对 Kubernetes API 中的 Pod 对象拥有创建权限的用户。

**修复方法**: 在可行的情况下，移除对集群中 Pod 对象的创建权限。
