# MITRE ATT&CK: T1562.001 - Disable or Modify Tools

**技术 ID**: T1562.001
**战术**: Defense Evasion
**平台**: Containers
**描述**: 攻击者可能会修改和/或禁用安全工具，以避免其恶意软件/工具及相关活动被检测到。这可能会以多种形式出现，例如终止安全软件进程或服务、修改/删除注册表项或配置文件以使工具无法正常运行，或者采用其他方法干扰安全工具的扫描或信息报告。攻击者还可能禁用更新，以阻止最新的安全补丁到达受害者系统上的工具。攻击者可能会通过合法的系统进程触发拒绝服务攻击。此前已观察到，Windows时间旅行调试（TTD）监控驱动程序可用于为安全工具（例如EDR）启动调试会话，并使该工具无法正常工作。通过将调试器挂钩到EDR进程中，EDR的所有子进程将被自动暂停。攻击者可以滥用Process Explorer驱动程序来终止任何EDR辅助进程（不受Windows保护进程轻量版保护的进程）。综合这些操作，将阻止任何重启服务的尝试，并导致该工具崩溃。攻击者还可能篡改安全工具部署和使用的工件。安全工具可能会对系统组件进行动态更改，以保持对特定事件的可见性。例如，安全产品可能会加载自己的模块和/或修改进程加载的模块，以方便数据收集。与指示器阻断类似，攻击者可能会解除挂钩或以其他方式修改这些由工具添加的功能（特别是那些存在于用户态或可能被攻击者访问的功能），以避免被检测到。

**常见方法**:
1. 修改或删除安全工具的配置文件、注册表项或其他相关工件。
2. 终止或禁用安全工具的进程或服务。
3. 篡改安全工具的部署和使用的工件。

**检测方法**:
- 对禁用或修改安全工具的 adversary 行为的检测，包括终止 AV/EDR 进程、停止服务、更改 Sysmon 注册表项或篡改排除列表。防御者会观察到进程/服务终止、注册表修改以及预期遥测的异常缺失情况。
- 检测攻击者通过终止守护进程、卸载内核模块或修改init/systemd服务配置来试图停止或禁用基于主机的安全代理的行为。
- 检测攻击者通过卸载启动代理/守护程序、修改配置文件或使用安全/卸载命令来移除代理，从而禁用端点安全工具的行为。
- 检测攻击者通过API调用或终止代理进程来禁用云监控和日志代理（如CloudWatch、Google Cloud Monitoring或Azure Monitor）的行为。
- 检测攻击者篡改容器运行时安全插件、禁用准入控制器或停止监控sidecar。
- 检测攻击者修改启动配置文件以禁用签名验证、日志记录或监控功能的行为。

**缓解措施**:
1. 定期验证工具是否正常运行——例如，所有安装了EDR或监控代理的预期主机是否都在向中央控制台签到。检查EDR以确保没有添加意外的排除路径。在Microsoft Defender for Endpoint中，可以使用Get-MpPreference cmdlet查看排除项。
2. 在适当情况下使用应用程序控制，特别是对于执行违反组织安全策略的工具（如已被滥用来削弱系统防御的 rootkit 清除工具）。确保企业系统上只使用和运行经过批准的安全应用程序。
3. 确保适当的流程和文件权限到位，以防止攻击者禁用或干扰安全服务。
4. 确保适当的注册表权限已到位，以防止攻击者禁用或干扰安全服务。
5. 确保适当的用户权限到位，以防止攻击者禁用或干扰安全服务。

**真实案例**:

**案例 1 - Contagious Interview（2025）**:

Contagious Interview已说服受害者禁用Docker和其他容器环境，并在其机器上原生运行代码，试图绕过容器隔离并确保设备被感染。

**参考**: https://socket.dev/blog/north-korean-contagious-interview-campaign-drops-35-new-malicious-npm-packages

**案例 2 - TeamTNT（2021）**:

TeamTNT已在云基础设施上禁用并卸载了阿里巴巴、腾讯和BMC云监控智能体等安全工具。
