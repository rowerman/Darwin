# MITRE ATT&CK: T1552 - Unsecured Credentials

**技术 ID**: T1552
**战术**: Credential Access
**平台**: Containers
**描述**: 攻击者可能会搜索受感染的系统，以查找并获取存储不安全的凭据。这些凭据可能存储和/或误放在系统上的许多位置，包括纯文本文件（例如shell历史记录）、操作系统或特定应用程序的存储库（例如注册表中的凭据），或其他专用文件/工件（例如私钥）。

**常见方法**:
1. 搜索系统文件，查找存储不安全的凭据的文件（例如shell历史记录、明文密码文件）。
2. 搜索系统注册表，查找存储不安全的凭据的键值对（例如Windows凭据）。
3. 搜索系统日志，查找存储不安全的凭据的事件（例如登录失败事件）。

**检测方法**:
- 未经授权的工具或脚本工具对bash历史记录、注册表凭据路径或私钥文件的异常访问，以及相关的文件和进程活动。
- 未授权用户或异常进程读取.bash_history、/etc/shadow等敏感文件或私钥目录。
- 未授权的进程或用户对~/Library/Keychains、~/.bash_history或终端命令历史的异常访问。
- 通过浏览器自动化或异常API令牌对密码管理器、单点登录会话或凭据同步服务进行的异常基于网络的访问或API抓取。
- 未经授权的API或控制台调用，用于检索或重置密码凭据、下载密钥材料或修改单点登录设置。
- 与入口点或编排上下文无关的进程对容器镜像层或挂载密钥（例如，Docker密钥）的访问。
- 使用配置备份工具或命令行界面访问来导出明文密码、本地用户哈希或简单网络管理协议字符串。

**缓解措施**:
1. 移除易受攻击的组策略首选项。
2. 主动搜索包含密码或其他凭证的文件，并在发现时采取措施降低暴露风险。
3. 在可能的情况下，将密钥存储在单独的加密硬件上，而不是本地系统中。
4. 限制对实例元数据API的访问。配置得当的Web应用程序防火墙（WAF）可能有助于防止外部攻击者利用服务器端请求伪造（SSRF）攻击来访问云实例元数据API。
5. 限制对敏感服务的网络访问，例如实例元数据API。
6. 为私钥使用复杂的密码短语，以增加破解难度。不要在注册表中存储凭据。制定组织政策，禁止在文件中存储密码。
7. 如果软件必须在注册表中存储凭据，那么应确保相关账户具有有限的权限，这样即使攻击者获取了这些凭据，也无法滥用它们。
8. 将文件共享限制在特定目录，且仅允许必要用户访问。
9. 确保开发人员和系统管理员意识到，在可能遗留在终端系统或服务器上的软件配置文件中存在明文密码所带来的风险。

**真实案例**:

**案例 1 - Pacu （2019）**:
Pacu 可以搜索敏感数据：例如，在 Code Build 环境变量、EC2 用户数据和 Cloud Formation 模板中。
