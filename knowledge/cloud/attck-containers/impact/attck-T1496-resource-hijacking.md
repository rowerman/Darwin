# MITRE ATT&CK: T1496 - Resource Hijacking

**技术 ID**: T1496
**战术**: Impact
**平台**: Containers
**描述**: 攻击者可能会利用被劫持系统的资源来完成资源密集型任务，这可能会影响系统和/或托管服务的可用性。资源劫持可能有多种不同形式。例如，攻击者可能会：利用计算资源来挖掘加密货币；将网络带宽出售给代理网络；生成短信流量以牟利；滥用基于云的消息服务发送大量垃圾信息。在某些情况下，攻击者可能会同时利用多种类型的资源劫持手段。

**常见方法**:
1. 利用计算资源来挖掘加密货币
2. 将网络带宽出售给代理网络
3. 生成短信流量以牟利
4. 滥用基于云的消息服务发送大量垃圾信息

**检测方法**:
- 持续的高CPU使用率，同时伴有可疑的命令行执行（例如，挖矿工具或混淆脚本）以及与挖矿/代理网络的出站连接
- 未经授权的进程出现异常的CPU/内存使用率，这些进程与已知的矿池存在出站连接，或者使用定时任务/脚本来维持持久性
- 具有高CPU使用率且能访问外部挖矿服务的后台启动代理/守护进程。
- 云虚拟机CPU使用率突然飙升，同时存在向矿池的出站流量以及未授权的实例创建。
- 未经授权的容器运行挖矿二进制文件或公共代理工具导致CPU使用率过高。
- 滥用云消息平台发送大量垃圾邮件或消耗基于配额的资源。

**缓解措施**:
1. 由于这种攻击技术是基于对系统功能的滥用，因此很难通过预防性控制措施来轻松缓解。
